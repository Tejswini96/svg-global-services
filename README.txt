SVG Global Services Website
===========================
Responsive HTML5, CSS3, JavaScript and Bootstrap 5 website.

Dummy images:
- Service cards, industry cards, founder portrait and project gallery use sample Unsplash stock photos.
- Replace all dummy photos with your company's approved images/CAD renders before publishing.
- The founder photo is only a placeholder and does not represent the actual founder.

Run:
1. Extract ZIP.
2. Open index.html in browser or VS Code Live Server.
3. Internet required for Bootstrap, Bootstrap Icons, Google Fonts and remote demo photos.

Before publishing:
- Verify company contact information.
- Add approved founder profile.
- Connect contact form to backend/email service. Current form only validates in browser.
- Verify service descriptions and project claims.
